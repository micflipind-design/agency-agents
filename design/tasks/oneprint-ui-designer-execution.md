# OnePrint UI Designer Execution Task

Use the attached project brief exactly: `oneprint-app-ui-24-frames.md`.

## Agent Role
Act as the **UI Designer** agent.

Create the OnePrint mobile app UI one screen at a time. The UI must be clean, premium, easy to understand, mobile-first, and consistent with the OnePrint orange / cream / charcoal visual system.

## Non-Negotiable Brand Rules
- Use primary orange gradient: `#F5421E → #F5A623`.
- Use Warm Coral `#EE8A60` only as a supporting accent.
- Use Charcoal `#282828` for text and structure.
- Use Pale Cream `#F5F3ED` for main app backgrounds.
- Use Montserrat Bold / ExtraBold or a very close rounded chunky font style.
- Logo: OnePrint wordmark with a small printer icon embedded in the `i` of `print` where possible.
- Use thick black extrude/drop-shadow only on logo, splash, and selected hero moments.
- Keep the actual app UI premium and minimal, not cartoonish.

## Required Build Order

### Phase 1 — Design System Board
Create a design system board before individual app screens.

Include:
1. Color tokens
2. Typography scale
3. Button styles
4. Cards
5. Status pills
6. Input/search fields
7. Bottom navigation
8. Printer status widget
9. File/template cards
10. Modal/bottom sheet styles
11. Icon style guide
12. Loading/empty/error state components

Acceptance criteria:
- Every component uses consistent radius, spacing, shadow, and typography.
- Primary buttons are orange gradient with white bold text.
- Text contrast meets WCAG AA.
- Mobile tap targets are at least 44 × 44 px.

### Phase 2 — Frames 1–6
Create these first six app screens:

1. Splash / Permission Onboarding
2. Home Dashboard
3. Printer Connection
4. Template Gallery
5. Template Search / Category
6. Template Detail / Editor

Frame quality checklist:
- Clear top-level purpose per screen.
- Obvious CTA.
- No clutter.
- Rounded premium card system.
- Consistent spacing and typography.
- Printer-related visual language is visible but not overused.
